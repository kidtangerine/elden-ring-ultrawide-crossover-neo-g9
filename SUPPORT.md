# Support

## Before asking for help

1. Confirm the game is fully closed.
2. Use Steam's **Verify integrity of game files** command.
3. Run `./scripts/diagnose.command`.
4. Compare the clean executable hash with the supported hash in the README.

For normal troubleshooting, open a
[compatibility report](https://github.com/kidtangerine/elden-ring-ultrawide-crossover-neo-g9/issues/new?template=bug_report.yml).
For questions, successful hardware reports, or setup discussion, use
[GitHub Discussions](https://github.com/kidtangerine/elden-ring-ultrawide-crossover-neo-g9/discussions).

Include the Elden Ring version, CrossOver version, macOS version, Mac model,
display resolution, clean executable SHA-256, and launcher log. Do **not**
upload game executables, saves, credentials, cookies, Steam databases, or a
CrossOver bottle archive.
